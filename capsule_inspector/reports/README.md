# Relatórios

Gerados localmente (ignorados pelo git): avaliações (`eval_*`), benchmarks (`benchmarks/`),
`experiments.csv`, `platform_<host>.json`.

`examples/` contém resultados **reais de execuções deste repositório com dados SINTÉTICOS em
contêiner x86_64** — demonstram o formato dos relatórios e que o encadeamento funciona; não têm
valor de validação nem representam desempenho no Raspberry Pi.
